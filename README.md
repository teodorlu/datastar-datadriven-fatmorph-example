# A data-driven, fat-morph approach with Datastar, Nexus and Replicant (on the server)

**Warning: This example currently does not reflect great Datastar usage.
If you've found this and want to learn Datastar, read [the official Datastar documentation].**

[the official Datastar documentation]: https://data-star.dev/

… because data-driven is amazing, and one server process and zero javascript build steps is easier on the brain.

## Run it locally

To run, either use the [application.garden CLI]

    garden run

, or run

    (hugin/start {})

from a REPL.

Finally, open http://localhost:7777/
